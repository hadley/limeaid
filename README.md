# Limeaid

A personal dinner planner and grocery-list builder, built as a replacement
for Mealime (which is shutting down). Seeded with the full scraped Mealime
recipe catalog and personalized with my own ratings and cooking history.

## What it does

- Suggests dinners for the week (weighted random sampling that balances
  old favorites against novelty)
- Builds a merged grocery list from the week's picks, organized by store
  department
- Marks meals cooked and captures ratings, which feed future suggestions
- Hands the grocery list off to HEB curbside via search URLs

## Stack

- Next.js + React in `web/`, deployed on Vercel
- Postgres (schema in `db/schema.sql`), seeded from `db/seed/`
- Scraping and data-prep scripts (R) in `scrape-recipes/`

## Development

```bash
cd web
npm install
npm run dev        # http://localhost:3000
npm run seed       # apply schema + load seed data (needs DATABASE_URL)
```
